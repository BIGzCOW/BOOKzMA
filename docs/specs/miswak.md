# مشخصات قابلیت: بخش مستقل مسباک

## شناسهٔ ROADMAP

پیشنهاد جدید؛ بخش مستقل «عادت و سلامت».

## چرا

کاربری که فقط برای ثبت عادت مسباک‌زدن و یادآوری‌هایش از ربات استفاده می‌کند بتواند بدون استفاده از امکانات کتاب‌خوانی عضو شود. این عضویت همچنین مخاطب مشخصی برای آموزش‌های مرتبط می‌سازد.

## رفتار از دید کاربر

- ورود به بخش اختیاری است و در onboarding کتاب‌خوانی اجباری نمی‌شود.
- کاربر تازه در صفحهٔ خوش‌آمد onboarding یک مسیر مستقیم برای بازکردن این بخش دارد؛ `/miswak` هم بدون تکمیل onboarding مطالعه قابل اجراست.
- کاربر هدف روزانهٔ ۱ تا ۵ نوبت انتخاب می‌کند و برای هر نوبت یک زمان به وقت منطقهٔ زمانی حساب تنظیم می‌کند.
- ساعت‌های پیشنهادی ۰۶:۳۰، ۱۳:۰۰، ۱۶:۰۰، ۱۹:۰۰ و ۲۲:۰۰ هستند؛ برای هدف‌های کوچک‌تر، آخرین ساعت‌ها پیش‌فرض می‌شوند (هدف ۱: ۲۲:۰۰، هدف ۲: ۱۹:۰۰ و ۲۲:۰۰) و قابل ویرایش‌اند.
- هر نوبت جداگانه ثبت می‌شود. روز فقط با تکمیل سهمیهٔ همان روز موفق است و استریک جاری/رکورد از روزهای موفق محاسبه می‌شود.
- هدف جدید از روز محلی بعد اعمال می‌شود؛ تاریخچهٔ روزهای گذشته تغییر نمی‌کند.
- بعد از خروج، یادآورها و کمپین‌های جدید متوقف می‌شوند؛ تاریخچه نگه داشته می‌شود. فعال‌سازی دوباره تاریخچه را بازمی‌گرداند، اما روزهای غیرفعال موفق محسوب نمی‌شوند.
- فعال‌سازی به‌روشنی اطلاع می‌دهد که همهٔ اعضای فعال این بخش ممکن است پیام‌های آموزشی ادمین را دریافت کنند. خاموش‌کردن جداگانهٔ آموزش وجود ندارد؛ خروج از بخش، آن را متوقف می‌کند.
- صفحهٔ بخش پیشرفت امروز، تقویم هفتگی، استریک فعلی و رکورد، آمار هفته/ماه و دستاوردهای مستقل را نشان می‌دهد.
- قابلیت‌های اجتماعی شامل چالش‌های ۷/۳۰ روزه، لیگ هفتگی و رفیق مسباک فقط با پیوستن داوطلبانه در دسترس‌اند. نام/رتبه فقط برای اعضای همان فعالیت نمایش داده می‌شود.
- چالش پیوسته پس از اولین روز محلیِ بسته‌شده‌ای که هدف کامل نشده، لغو می‌شود؛ روز جاری تا پایان همان روز فرصت دارد.

## اثر روی کل محصول

- مسیرها: منوی دائمی و صفحهٔ اختصاصی؛ نمایش خلاصهٔ استریک در خانه/پروفایل؛ یادآوری پس‌زمینه؛ ثبت در رویدادهای روزانه. خلاصهٔ مطالعه، لیدربورد مطالعه و API فعلی عوض نمی‌شوند.
- پنل ادمین: انتخاب مخاطب «همه» یا «اعضای فعال مسباک»، پیش‌نمایش تعداد، تأیید/لغو و گزارش ارسال. اعضای فعال و استفادهٔ ۷/۳۰روزه و نرخ تکمیل هدف به داشبورد اضافه شود.
- رسانهٔ کمپین: متن، یا یک عکس/ویدئو با کپشن و دکمهٔ لینک معتبر؛ ارسال پایدار از صف موجود.
- مخاطبان هنگام ساخت کمپین snapshot می‌شوند، ولی عضویت پیش از هر ارسال هم بررسی می‌شود تا فردی که خارج شده پیام در صف را دریافت نکند.
- کاربران موجود هیچ‌وقت خودکار عضو نمی‌شوند. کاربران جدید می‌توانند بدون تکمیل onboarding مطالعه وارد این بخش شوند.
- روزهای مسباک، استریک مطالعه، فریز و comeback از هم جدا هستند.

## داده و حریم خصوصی

- تنظیمات عضویت/هدف، زمان‌های یادآوری، روزهای ثبت‌شده و هدف snapshot شده، نشان‌ها، چالش‌ها و ارتباط‌های اجتماعی مستقل ذخیره شوند.
- داده‌ها به Telegram ID و فعالیت فرد مربوط‌اند؛ در متن کمپین، snapshot تحویل و آمار تجمیعی نگهداری می‌شوند.
- حذف حساب با cascade همهٔ داده‌های این بخش را حذف می‌کند.
- خروج از بخش، عضویت مخاطب و یادآورها را غیرفعال می‌کند، رضایت لیگ را خاموش می‌کند، چالش‌ها/رفاقت‌های فعال را می‌بندد و دعوت‌های صادرشده را حذف می‌کند؛ تاریخچهٔ فردی نگه داشته می‌شود.
- هیچ اطلاعات شخصی یا محتوای یادآوری در log ثبت نشود.

## حالت‌های خاص

- ثبت نوبت با کلید یکتای کاربر/روز/نوبت ایدمپوتنت است؛ ثبت هم‌زمان سهمیه را رد نمی‌کند.
- ساعت یادآوری برای هر کاربر یکتا است؛ تغییر هم‌زمان دو نوبت به یک ساعت با قفل profile و قید پایگاه داده رد می‌شود.
- تاریخ روز با timezone کاربر محاسبه می‌شود. هدف هر روز ثابت است؛ ساعت محلی هنگام DST با timezone database تفسیر می‌شود.
- هر ساعت یادآوری حداکثر یک بار در روز ارسال می‌شود؛ یادآورهای موعدگذشته بیش از ۱۰ دقیقه حذف می‌شوند و هدف کامل‌شده یادآورهای بعدی را لغو می‌کند.
- خطای موقت Telegram طبق retry محدود صف مدیریت می‌شود؛ خطای دسترسی کاربر او را از تحویل‌های آتی حذف می‌کند.
- task پس از restart از پایگاه داده ادامه می‌دهد؛ اجرای چند نمونهٔ برنامه پشتیبانی نمی‌شود.

## امنیت و مجوز

- همهٔ callbackها سمت سرور مالکیت، عضویت و ورودی را اعتبارسنجی می‌کنند؛ callback روز منقضی رد می‌شود.
- هر عملیات مدیریتی سمت سرور با allowlist ادمین مجاز می‌شود؛ تعداد گیرنده و محتوا پیش از تأیید نشان داده می‌شود.
- متن کاربر و لینک‌ها اعتبارسنجی/escape می‌شوند و محدودیت Telegram رعایت می‌شود.
- فیچر API جدید، dependency جدید یا سرویس خارجی اضافه نمی‌کند.

## خارج از محدوده

- تغییر استریک مطالعه یا کاربرد freeze/comeback در فعالیت جدید.
- اضافه‌کردن خودکار کاربران، ارسال تبلیغات یا پیام‌رسانی مستقیم به دوستان.
- لیدربورد عمومی یا نمایش اجتماعی بدون رضایت.
- تغییر API یا دسترسی اجباری به کانال/کتاب‌خوانی.

## تصمیم‌های باز برای مالک

- ندارد؛ قواعد این spec با تأیید شروع پیاده‌سازی نهایی شده‌اند.
