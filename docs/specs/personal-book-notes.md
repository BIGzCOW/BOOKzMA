# مشخصات قابلیت: یادداشت خصوصی کتاب

## شناسهٔ ROADMAP

B-07

## چرا

کاربر می‌خواهد توضیح، نظر یا خلاصهٔ شخصی خودش را کنار کتابی که در کتابخانه دارد نگه دارد.

## رفتار از دید کاربر

- از جزئیات هر کتاب، کاربر می‌تواند یک یادداشت خصوصی ۱ تا ۳۵۰۰ نویسه‌ای اضافه یا ویرایش کند.
- یادداشت برای کتاب‌های فعال، تمام‌شده، برنامه‌ریزی‌شده و آرشیوشده قابل دیدن/ویرایش است.
- کاربر می‌تواند یادداشت را پاک کند؛ پاک‌کردن فقط متن یادداشت را حذف می‌کند، نه کتاب یا سابقهٔ صفحات را.
- متن یادداشت در صفحهٔ جداگانه نمایش داده می‌شود تا متن کامل با جزئیات کتاب از سقف پیام Telegram عبور نکند.
- ورود/ویرایش/پاک‌کردن فقط در private chat انجام می‌شود.

## اثر روی کل محصول

- مسیرها: دکمهٔ contextual در جزئیات کتاب، یک callback برای ویرایش، یک callback برای پاک‌کردن و یک FSM state برای دریافت متن.
- API: بدون تغییر؛ API فعلی کتابخانه را عرضه نمی‌کند.
- پنل ادمین/آمار: KPI یا action لازم نیست؛ متن خصوصی کاربر هرگز در تحلیل یا log وارد نمی‌شود.
- کاربران موجود: ستون جدید nullable است و همه با یادداشت خالی شروع می‌کنند.
- حذف حساب: یادداشت با ردیف کتاب و cascade حذف حساب پاک می‌شود.

## داده و حریم خصوصی

- `user_books.note` از نوع Text nullable؛ حداکثر ۳۵۰۰ نویسه.
- متن فقط از query مالک‌دار همان `user_id` خوانده/تغییر می‌کند؛ هنگام نمایش HTML escape می‌شود.
- متن در FSM فقط تا تکمیل فرم لازم است؛ backup پایگاه‌داده شامل دادهٔ کاربر طبق سیاست فعلی است.

## حالت‌های خاص

- متن خالی ذخیره نمی‌شود؛ «پاک‌کردن یادداشت» مسیر جداگانه دارد.
- ورودی بیش از ۳۵۰۰ نویسه رد می‌شود و وضعیت فرم برای اصلاح حفظ می‌شود.
- تغییر/پاک‌کردن callback روی کتابی که مالک نیست یا وجود ندارد رد می‌شود.
- ناوبری به بخش دیگر فرم باز را می‌بندد؛ restart نیز طبق رفتار فعلی FSM فرم را می‌بندد.
- Markdown/HTML کاربر هنگام نمایش escape می‌شود و به markup تبدیل نمی‌شود.

## امنیت و مجوز

- تمام عملیات query/update هم‌زمان با `book_id` و `user_id` شرط می‌خورند.
- handlerها فقط در private router هستند؛ group callback پیش از دسترسی به داده رد می‌شود.
- callback فقط ID محدود کتاب را می‌پذیرد؛ متن یادداشت در callback یا لاگ قرار نمی‌گیرد.

## خارج از محدوده

- خلاصهٔ تولیدشده، یادداشت صوتی، rating، نقد عمومی، اشتراک‌گذاری یا چند یادداشت تاریخ‌دار.
- افزودن note به API، dashboard ادمین یا leaderboard.

## تصمیم‌های باز برای مالک

ندارد؛ یک فیلد آزاد خصوصی و قابل‌ویرایش برای هر کتاب تأیید شده است.
